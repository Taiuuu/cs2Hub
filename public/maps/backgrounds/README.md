# Fondos de Mapas

En esta carpeta van las imágenes de fondo (JPG/JPEG) para cada mapa.

## Convención de nombres

Usar el ID del mapa en minúsculas:
- dust2.jpg
- mirage.jpg
- nuke.jpg
- inferno.jpg
- ancient.jpg
- anubis.jpg
- cache.jpg
- overpass.jpg
- train.jpg
- vertigo.jpg

## Especificaciones

- **Formato**: JPG o JPEG
- **Tamaño recomendado**: 800x1000px (relación 3:4)
- **Peso**: < 150KB (optimizado para web)
- **Contenido**: Screenshot o render del mapa

## Ejemplo de uso en componente

```tsx
fondo: '/maps/backgrounds/dust2.jpg'
```
