# Game Radar de Mapas

En esta carpeta van los radares/minimapas del juego en PNG con transparencia.

## Convención de nombres

Usar: [mapName]_gameradar.png

Ejemplo:
- mirage_gameradar.png (como se especificó en los requisitos)

## Especificaciones

- **Formato**: PNG con transparencia
- **Tamaño recomendado**: 512x512px (cuadrado)
- **Peso**: < 100KB
- **Contenido**: Minimap del juego para la página de detalles

## Ejemplo de uso

Se puede usar en la página de detalle del mapa para mostrar el radar y los callouts superpuestos.
