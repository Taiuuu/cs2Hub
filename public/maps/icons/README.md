# Iconos de Mapas

En esta carpeta van los logos/iconos (PNG con transparencia) para cada mapa.

## Convención de nombres

Usar el ID del mapa en minúsculas:
- dust2.png
- mirage.png
- nuke.png
- inferno.png
- ancient.png
- anubis.png
- cache.png
- overpass.png
- train.png
- vertigo.png

## Especificaciones

- **Formato**: PNG con transparencia
- **Tamaño recomendado**: 200x200px (cuadrado)
- **Peso**: < 50KB
- **Contenido**: Logo del mapa centrado sobre fondo transparente

## Ejemplo de uso en componente

```tsx
icono: '/maps/icons/dust2.png'
```
